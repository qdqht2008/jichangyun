# 网站流量优化 P3：问题导向分发素材包设计

**日期：** 2026-07-07
**状态：** 已实施
**范围：** `docs/distribution/2026-07-problem-led-launch-kit.md` 与站点审计

## 目标

把现有高价值指南转化为可以人工发布的社区短文和 60 秒视频脚本。每组素材先解决一个明确问题，再提供一个站内深度指南链接；不以商家、优惠、测速或夸张效果作为点击诱因。

素材包只生成草稿、UTM 示例和发布检查表，不自动发布、不登录外部平台、不创建账号，也不声称已经带来流量或外链。

## 交付内容

新增版本化文档：

`docs/distribution/2026-07-problem-led-launch-kit.md`

本批包含三组活动：

1. 订阅更新失败：落地到 `https://www.jichangyun.top/guide/subscription-update-failed/`，强调下载失败、授权线索和解析失败的分支判断。
2. 已连接但无法上网：落地到 `https://www.jichangyun.top/guide/connected-but-no-internet/`，强调节点、系统代理/TUN、DNS 和本地网络的单变量排查。
3. 线路怎么选：落地到 `https://www.jichangyun.top/tutorial/line-selection/`，沿用已证据化的三段链路核验口径，把直连、公网中转和 IEPL/IPLC 作为提问起点，而不是体验结论。

每组活动固定包含：

- 内容目的与目标读者
- 三个标题
- 社区短文
- 60 秒视频分镜
- 短摘要
- 主链接
- 可选追踪参数

## 内容边界

- 不写测速、延迟、带宽、成功率、稳定率、解锁率或运营时长数字。
- 不推荐具体机场，不放商家注册链接、套餐价格、活动或推广码。
- 不建议关闭防火墙、安全软件、批量删除配置或复制来源不明的配置。
- 每条内容只给可逆动作，并说明何时停止修改、转向客户端官方文档或服务商支持。
- UTM 示例只包含 `source`、`medium`、`campaign`、`content`，不包含用户标识、商家参数或敏感信息。

## 完成条件

三组素材可供人工审阅和发布，事实与当前指南一致，安全边界明确，自动审计通过并创建本地提交。不推送、不部署、不代发外部平台内容。
