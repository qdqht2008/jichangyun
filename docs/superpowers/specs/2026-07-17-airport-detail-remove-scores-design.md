# 机场详情页移除评分设计

## 目标

机场详情页不再展示编辑评分、四维评分或官网健康度分值，但继续保留对读者有直接参考价值的事实型资料。综合榜单 `/rankings/` 的历史评分、公式和排序不变。

## 范围

本次修改 11 个活跃机场详情页共用的动态资料模块：

- 删除编辑总分；
- 删除官网健康度、性价比、易用性和风险安全度四维评分；
- 删除“官网健康度 X/100”等分值表达；
- 删除详情页中的“评分依据”“公开资料评分”等文案；
- 保留风险状态、月均门槛、试用资料、最近核对、官网检查事实、客户端、流媒体/AI、节点地区、风险结论和站内链接。

本次不修改：

- `/rankings/` 的评分展示、历史平均、筛选和排序；
- `data/airports.json` 或 `data/airport-health-history.json` 的数据结构；
- 官网监测脚本及评分计算函数；
- 机场详情页原有套餐正文、CTA、FAQ、来源和评论区。

## 实现设计

继续使用现有 `js/airport-report.js` 渲染详情页事实模块，不建立第二套脚本。

脚本删除 `calculateScore` 依赖、总分计算、评分项渲染函数和评分区块。模块标题改为“公开资料与风险快照”，说明文字只描述资料来源和能力边界。官网检查区只展示本次请求成功次数、响应时间、状态码、错误信息和检查时间，不展示数值评分。

11 个活跃机场详情页保留现有挂载点和模块脚本，仅把挂载点的无障碍标签从“公开资料评分”改为“公开资料快照”。这样原有页面结构和加载路径不变，修改范围最小。

删除只服务于详情页评分总分和四维评分卡片的 CSS 规则，包括移动端对应布局声明。事实模块现有风险、能力、官网状态和链接样式继续复用。

数据加载失败时，提示改为“公开资料载入失败”，并继续明确原有套餐正文可阅读。

## 验收与测试

自动测试覆盖：

- 11 个活跃详情页仍各有一个资料挂载点和模块脚本；
- 11 个挂载点使用“公开资料快照”无障碍标签，不再使用“公开资料评分”；
- `airport-report.js` 不包含 `calculateScore`、编辑评分、评分权重、`/100` 分值或四维评分区块；
- 脚本仍渲染风险、价格、试用、最近核对、官网检查事实、能力和风险结论；
- `/rankings/` 的历史评分测试继续通过；
- 全部现有站点测试零失败、零跳过。

在当前 8002 本地服务上检查桌面端和 390×844 移动端：资料模块正常加载、没有评分内容、没有横向滚动、控制台没有本站错误，原有文章正文仍可阅读。

## 完成标准

1. 11 个活跃机场详情页不再向用户或无障碍树暴露评分信息；
2. 已确认的事实信息全部保留；
3. 榜单评分与历史数据行为没有变化；
4. 自动测试与浏览器验收实际执行并通过；
5. 不修改或提交用户已有的 `.DS_Store`。
