# 网站流量优化 P0 设计

## 背景与目标

当前站点具备独立标题、描述、canonical、Sitemap 和部分结构化数据，但首页内容偏薄，顶部导航与首页分类卡片把分类流量导向单篇详情页，移动端导航存在截断感，首页还加载了没有实际价值的评论区。机场详情页中的推广链接和内容图片也缺少统一的 SEO 与性能属性。

本批目标是在不引入框架、构建步骤或动态数据的前提下，完成最高优先级的技术与信息架构优化：

- 把首页改造成三个内容簇的静态内容枢纽。
- 强化 `/jichang/`、`/tutorial/`、`/guide/` 三个聚合页的站内权重。
- 改善 390px 移动端导航和首页阅读体验。
- 规范商业推广链接、图片加载属性和 Sitemap。
- 建立可重复执行的零依赖站点审计测试。

本批不重写机场评测正文，不添加搜索或筛选，不批量转换图片格式。

## 已确认前提

- 生产环境为纯 Cloudflare Pages 静态部署。
- 页面评论使用 Giscus；`waline/` 不是生产运行依赖。
- Cloudflare Pages 会自动排除 `node_modules`，因此本批不新增部署排除配置。
- 仓库中的 Vercel 部署说明与 `vercel.json` 已过时，但本批只记录为待清理项，不删除配置。
- 当前未跟踪的 `AGENTS.md` 不纳入本批提交。

## 首页信息架构

采用“内容枢纽”方案，保留现有暖色主题、品牌名称和首页 H1“优质机场推荐”。

首页结构依次为：

1. 现有品牌区与主标题。
2. 三张分类主卡片，分别指向 `/jichang/`、`/tutorial/`、`/guide/`。
3. 两个重点入口：机场选择指南与常见故障排查。
4. 三组内容列表：机场推荐、客户端教程、避坑百科，每组展示四条现有内容。
5. 最近更新区域，展示真实更新日期。
6. 现有页脚。

首页不再加载 Giscus。首页新增内容全部使用普通可抓取的 HTML 链接，不依赖 JavaScript 注入。

## 导航与移动端

顶部导航中的三个分类项统一指向聚合页：

- 机场推荐 → `/jichang/`
- 使用教程 → `/tutorial/`
- 机场百科 → `/guide/`

移动端保持单行导航。通过缩小字体间距和链接内边距让常见手机宽度容纳完整导航；极窄屏仍允许横向滚动，并保留边缘间距，避免末尾菜单不可发现。首页新增区块在移动端改为单列。

## 推广链接与图片

仅对机场详情页中确认属于推广、注册或返佣入口的 CTA 添加：

```html
rel="sponsored nofollow noopener"
```

官方文档、项目主页等普通外链不标记为商业链接。

正文图片统一增加：

- `loading="lazy"`
- `decoding="async"`
- 与源文件一致的 `width` 和 `height`

站点 Logo 不使用懒加载。本批不转换 WebP，避免大范围替换资产与 URL。

## Sitemap

Sitemap 覆盖全部公开 HTML 页面，包括联系页。每个 URL 仅保留：

- `loc`
- 与页面重要内容实际修改时间对应的 `lastmod`

移除不会被 Google 使用且当前容易造成误导的 `priority` 和 `changefreq`。本批修改到的首页与聚合页使用本次变更日期；未修改正文的页面保留其最近一次实际内容修改日期。

## 测试与验收

新增一个只使用 Node.js 内置模块的站点审计脚本。实现前先运行并确认它因当前缺陷失败，再以最少改动使其通过。测试覆盖：

- 顶部导航与首页分类入口指向三个聚合页。
- 首页不存在 Giscus 容器或客户端脚本。
- 首页存在三个内容簇及重点入口。
- Sitemap 覆盖全部公开页面，且不包含 `priority` 或 `changefreq`。
- 商业 CTA 带有 `sponsored nofollow noopener`。
- 正文图片具备懒加载、异步解码和有效尺寸。
- 所有根路径站内链接都能映射到现有文件。

自动检查通过后启动本地静态服务器，并在桌面和 390px 移动端验证：

- 页面没有横向内容溢出。
- 顶部导航可访问全部菜单。
- 首页区块顺序、链接和响应式布局正确。
- 浏览器控制台没有由本批变更引入的错误。

本批不推送、不部署，因此只声明本地验证结果，不声明生产环境已经更新。

## 变更边界

允许修改：

- `index.html`
- `css/main.css`
- `js/nav.js`
- `sitemap.xml`
- 机场详情页中的商业 CTA
- 含正文图片的 HTML 页面
- 新增站点审计测试
- `.gitignore`

不修改：

- 机场评测正文与推荐排序
- 现有视觉主题变量
- Giscus 在文章页中的配置
- `waline/` 目录
- Cloudflare 项目设置
- 当前未跟踪的 `AGENTS.md`
- 过时的 `vercel.json`；该文件留作后续部署清理项
