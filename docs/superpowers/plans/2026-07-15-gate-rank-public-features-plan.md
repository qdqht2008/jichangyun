# 榜单、机场报告、风险监测与检测工具实施计划

**目标：** 在保留当前静态网站架构与暖色品牌的前提下，为现有机场增加官网健康度、透明编辑评分、综合榜单、组合筛选、风险监测、结构化机场报告和出口地区/流媒体基础可达性检测。

**设计依据：** `docs/superpowers/specs/2026-07-15-gate-rank-public-features-design.md`

**架构：** 静态 JSON 是榜单、风险页和机场报告的唯一事实源；无依赖 ES 模块负责校验、评分、排序和筛选；官网健康度由按需运行的 Node 维护脚本采集；只有检测工具使用无状态 Vercel API。

## Task 1：锁定数据契约与业务意图（RED）

**新增：** `tests/airport-features.test.mjs`

1. 定义机场记录必需字段、枚举、日期、URL 和 `null` 语义测试。
2. 要求活跃机场列表覆盖当前机场中心的 11 个卡片；已退役的光年 VPN 与龙淼云不进入榜单。
3. 锁定评分公式：官网健康度 35%、性价比 25%、易用性 20%、风险安全度 20%。
4. 锁定风险门槛：`normal` 必须排在 `watch` 之前，`watch` 必须排在 `high` 之前，高分不能越级。
5. 锁定评分资料不足规则：任何评分输入缺失时不生成总分。
6. 锁定搜索、风险、价格、试用、客户端和流媒体组合筛选行为。
7. 锁定同分时按中文名称稳定排序。
8. 先运行目标测试，确认因实现和数据尚不存在而失败，而非测试语法错误。

## Task 2：实现官网健康度维护脚本（RED → GREEN）

**新增：** `scripts/check-airport-health.mjs`、`tests/check-airport-health.test.mjs`

1. 将单个 URL 检查拆为可测试函数：最多跟随有限重定向、8 秒超时、记录最终 URL 与状态码。
2. 对每个官网执行三次请求，使用确定性中位数函数汇总响应时间。
3. 对 HTTPS 连接记录证书有效期；HTTP 或无法读取证书时显式为 `null`。
4. 实现官网健康度公式：可达性 50 分、有效 HTTPS 证书 30 分、响应时间 20 分。
5. 支持测试注入请求函数，自动测试不依赖真实网络。
6. 支持 `--write` 显式写回 `data/airports.json`；默认仅输出检查结果，避免意外改写。
7. 记录 `checkedAt` 和执行环境说明，不将官网状态描述为节点或线路稳定性。
8. 运行脚本单元测试直至通过。

## Task 3：建立静态事实源与纯函数模块（GREEN）

**新增：** `data/airports.json`、`data/risk-events.json`、`js/airport-data.mjs`

1. 从现有机场中心卡片与详情页提取 11 个活跃机场的 slug、名称、详情 URL、公开官网、最低价格、试用、套餐周期和已明确归因的能力字段。
2. 不把商家线路、速度或解锁宣传转换为本站测试结论；能力字段保留资料来源与核对日期。
3. 为每个机场填写性价比、易用性和风险安全度的人工依据；无依据字段使用 `null`。
4. 首次运行官网健康度脚本，保存公开可复核的健康检查结果；无法检查的机场保留显式失败状态。
5. 建立风险事件文件；没有可核验异常的机场使用 `normal`，存在既有风险说明的机场按证据使用 `watch` 或 `high`，不凭总分反推。
6. 实现加载、校验、评分、风险优先排序、稳定同分排序、搜索与组合筛选纯函数。
7. 运行 Task 1 与 Task 2 测试直至通过。

## Task 7：实现检测 API 与浏览器探测（RED → GREEN）

**新增：** `api/streaming-check.js`、`tools/streaming-check/index.html`、`js/streaming-check.js`、`tests/streaming-check-api.test.mjs`

**修改：** `css/main.css`

1. 先锁定 POST-only、请求头解析、未知地区、`Cache-Control: no-store`、不写日志和响应结构测试。
2. API 优先读取 Vercel 国家/地区请求头和标准代理 IP 请求头，只返回本次响应需要的字段。
3. API 不调用第三方 IP 数据服务、不写数据库、不生成检测历史。
4. 页面由用户点击后开始检测；API 与单项资源探测各自 8 秒超时。
5. 浏览器并行探测 ChatGPT、Netflix、Claude、TikTok、Disney+ 与 HBO Max 的公开基础资源。
6. 分开显示“官方地区覆盖推断”和“基础资源可达性”；跨域或反机器人失败显示“浏览器限制”。
7. 明确结果不能证明账号登录、完整片库或实际播放成功。
8. 单项失败不取消其他结果；API 失败不伪造 IP 或地区。
9. 运行 API 与页面目标测试直至通过。
