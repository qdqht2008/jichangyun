Search Console 里也出现了“杨帆云”这一写法；本文统一按商家名称“扬帆云”整理，不把误写当作另一个服务。

扬帆云当前提供 LV1 至旗舰版五档周期套餐，月付从 ¥19.99 到 ¥88.99。官方套餐页同时列出私人定制和三个周期优惠码；长周期购买前应先核对设备数、速率、节点等级和最终结算金额。

本文仅整理公开资料，实际体验因地区、运营商、设备和时段而异。

适合人群

  • 希望按设备数和周期流量选择套餐的用户
  • 需要在 200Mbps 至 1Gbps 标称速率之间分档的用户
  • 愿意在结算前复核当前优惠的长周期用户

不适合人群

  • 需要超过 8 台设备同时使用的用户
  • 把商家“IEPL”标签直接等同于本地实际体验的用户
  • 未确认优惠叠加规则就购买两年套餐的用户

可核验特点

  • 五档周期套餐均提供月、季、半年、年和两年周期
  • 设备限制从 2 台逐档增加到 8 台
  • 官方页提供半年、年付和两年付优惠码

限制与购买前确认

  • LV1 至 LV4 均有明确标称速率上限
  • 私人定制的节点和独立 IP 需要另行付费
  • 优惠是否叠加、何时结束未见官方页说明

节点等级与私人定制

商家套餐页将 LV1、LV2 标为标准节点，LV3 标为部分 IEPL 专线，LV4 标为全 IEPL 专线；旗舰版被描述为大流量、家庭共享定位。这些是商家套餐分类，不代表本站对线路类型、游戏或办公表现的验证。

私人定制以 1.2TB、两年套餐 ¥2135.76 为基础，购买后需联系客服；定制节点另收费，独立 IP ¥200/月/个起，两年起订。
