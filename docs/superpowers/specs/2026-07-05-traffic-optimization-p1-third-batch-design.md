# 网站流量优化 P1：第三批机场评测重构设计

**日期：** 2026-07-05
**状态：** 已确认，待实施计划
**范围：** 扬帆云、宇宙云、万象加速详情页，机场汇总页与 Sitemap

## 1. 目标

将第三批三个旧版机场页面改造成与前两批一致的编辑型评测页，使读者无需从截图或宣传段落中自行提取价格、流量和限制，同时移除没有当前证据支持的绝对化 SEO 与体验结论。

本批保持纯 Cloudflare Pages 静态架构、现有暖色视觉与商业入口，不增加服务端、登录、测速或运行时数据源。

## 2. 证据来源与边界

套餐事实来自用户于 2026-07-05 提供并明确确认为当前官方套餐页的文字：

- 扬帆云：周期套餐、私人定制、设备与速率限制、当前优惠码。
- 宇宙云：五档套餐、周期折扣及商家对线路、解锁和客户端的描述。
- 万象加速：六档套餐、流量、限速、线路描述、地区描述和退款规则。

公开注册入口只用于核对商家页面仍可访问，不作为套餐事实的替代来源。第三方文章不用于当前价格或性能结论。

统一证据规则：

- 套餐名、价格、流量、速率、设备数和退款规则可写成“官方套餐页显示”。
- IEPL、CN2、CUII、CMI、流媒体/AI 解锁、自研客户端、新疆可用等均是商家声明，不改写成本站验证。
- 不写本站测速、延迟、稳定性、解锁率、晚高峰表现或运营年限。
- 页面统一使用：“本文仅整理公开资料，实际体验因地区、运营商、设备和时段而异。”
- 不显示推广或佣金披露；商业 CTA 保持 `rel="sponsored nofollow noopener"`。

## 3. 共同页面结构

三页采用同一信息架构：

1. `review-meta`：资料来源、核验日期和体验边界。
2. 一句话结论：只总结可核验的价格门槛、流量或限制。
3. `适合人群` / `不适合人群`：由套餐结构和明确限制推导，不推断性能。
4. `可核验特点`：套餐页直接陈述的事实。
5. `限制与购买前确认`：退款、设备、速率、含糊规则和商家声明边界。
6. 响应式文字套餐表。
7. 商业 CTA 与谨慎体验提示。
8. `信息来源`：官方套餐页及必要的商家公开入口。
9. FAQ 和相关指南内链。

样式优先复用 `css/main.css` 已有评测组件。只有在三页确有共同缺口时才做最小 CSS 补充，不重做视觉系统。

## 7. SEO、结构化数据与站内入口

- 三页标题和描述保留品牌与套餐搜索意图，删除“稳定、优质、全解锁、专业游戏、跨境办公”等未经验证的效果保证。
- Article JSON-LD 使用编辑部作者、正式 canonical 和 `dateModified: 2026-07-05`。
- FAQ 只回答套餐、重置、设备、退款与购买前核验，不创建性能答案。
- 机场汇总页只更新这三张卡片的摘要和核验状态，不改其他旧页。
- Sitemap 只更新三张详情页与机场汇总页的 `lastmod` 为 2026-07-05。
- 保留现有商业 URL，不在正文、测试报错或设计文档中复制完整注册链接查询串或其中的邀请码。

## 8. TDD 与验证

### 8.1 自动审计

先写失败测试并观察 RED，再实施：

- 三页具备统一评测结构、文字套餐表、来源和谨慎提示。
- 表格锁定每档官方价格、流量、速率、设备或退款事实。
- 扬帆云优惠与私人定制信息完整，且不推算叠加价格。
- 宇宙云“重置 9 折”必须同时出现条件未确认提示。
- 万象加速“不设退款”出现在显著风险区，线路/媒体/新疆均有商家归因。
- 三页不出现本站测速、绝对稳定、保证解锁、保证新疆可用等无证据措辞。
- CTA 的 `rel` 保持 `sponsored nofollow noopener`。
- JSON-LD、汇总页和 Sitemap 日期一致。

### 8.2 浏览器验证

- 桌面和 390px 宽度检查三页。
- 套餐表仅在自身容器横向滚动，页面无整体溢出。
- 检查首屏限制、CTA、来源、FAQ 与相关指南链接。
- 控制台无本站静态资源错误。

## 9. 完成条件与非目标

完成条件：三页事实与官方资料一致，体验和线路声明归因清楚，全量 Node 审计零失败零跳过，浏览器桌面/移动验证通过，创建本地提交。

本批不包含：

- 光年梯、龙猫云、Quick Cloud 或其他旧页。
- 本站测速、购买套餐、注册商家账号或验证解锁。
- 月度稳定性报告、分享图批量覆盖或其他 P3 工作。
- 推送、Cloudflare 部署或 GA4 管理端修改。
