# 机场详情页移除评分实施计划

**目标：** 从 11 个活跃机场详情页移除全部评分表达，保留事实型资料模块，并确保综合榜单评分不受影响。

**设计依据：** `docs/superpowers/specs/2026-07-17-airport-detail-remove-scores-design.md`

## Task 1：锁定无评分详情页意图（RED）

修改 `tests/airport-features.test.mjs`：要求每个详情页保留资料挂载点与模块脚本，但无障碍标签改为“公开资料快照”；要求 `js/airport-report.js` 不再包含评分计算、评分区块、分值或评分失败提示，同时仍包含已确认的事实字段。

## Task 2：精简共享详情报告（GREEN）

修改 `js/airport-report.js`：删除总分、四维评分和官网健康度分值；保留风险、价格、试用、核对日期、官网检查事实、能力、风险结论和链接；将标题及错误提示改为事实型表述。

## Task 3：同步详情页语义与样式

修改 11 个活跃 `jichang/*/index.html` 的挂载点标签；删除 `css/main.css` 中仅服务于已移除评分总分和评分卡片的规则，不改变其他报告布局。

## Task 4：验证

运行目标测试、全部 Node 测试、脚本语法检查和 `git diff --check`。在 8002 服务上验证桌面与 390×844 移动视口：详情模块无评分文字、事实信息存在、原正文存在、无横向滚动且控制台无错误；同时确认榜单历史评分仍加载。
