Clash 退出后无法上网怎么办？

作者优质机场推荐编辑部 依据系统代理与 Mihomo 官方资料 更新2026-07-10

先判断：是全系统没网，还是只有浏览器没网？

Clash 退出后无法上网，常见原因包括系统代理仍指向本地端口、浏览器代理扩展未停用、TUN 虚拟网卡仍影响路由、DNS 缓存异常，或另一个 VPN、加速器继续接管流量。

系统代理残留不是唯一原因。先恢复普通网络，再决定是否重新开启客户端。

两分钟恢复步骤

  1. 关闭浏览器代理扩展、其他 VPN 或加速器，只保留系统网络。
  2. 检查 Windows 或 macOS 的系统代理，把无效的本地代理地址取消。
  3. 换一个浏览器测试，区分浏览器单独代理和系统代理。
  4. 如果之前开启过 TUN，确认客户端已完全退出，虚拟网卡和路由不再残留。
  5. 仍无法恢复时，记录当前代理设置、客户端日志和网络环境；每次改动无效就回退，不继续批量删除配置。

按可逆顺序继续排查

1. Windows 系统代理

Windows 可从“设置 → 网络和 Internet → 代理”检查手动代理。如果代理服务器仍指向本机端口，而 Clash 已退出，浏览器就可能继续把请求发往不存在的本地服务。

2. macOS 系统代理

macOS 可从“系统设置 → 网络 → 当前网络 → 详细信息 → 代理”检查代理项。不同 macOS 版本入口名称可能略有差异，但排查目标相同：确认没有残留无效代理地址。

3. 浏览器代理与其他网络工具

部分浏览器扩展会独立设置代理，不完全跟随系统代理。另一个 Clash 客户端、VPN 或加速器也可能继续接管流量。保持单变量排查，才能判断是系统代理、浏览器代理还是其他工具。

4. TUN、虚拟网卡和 DNS

如果退出前启用过 TUN，问题可能来自虚拟网卡、路由或 DNS 状态。优先用客户端正常关闭 TUN 并恢复普通网络；不要直接删除网络适配器、配置文件或证书。

安全停止条件

  • 普通网络不能恢复时，先停止继续改客户端设置。
  • 代理设置显示由组织策略管理时，联系网络管理员。
  • 需要提交日志时，遮盖订阅 URL、令牌、账号、节点地址和本地 IP。
  • 不要批量删除网络配置；先保留现状，确认哪一项导致断网。

常见问题

Clash 退出后无法上网最先检查哪里？

先检查系统代理和浏览器代理是否仍指向本地端口，再确认普通网络能否在没有代理工具时恢复。

系统代理关掉了为什么浏览器仍然没网？

浏览器可能有独立代理扩展、企业策略或缓存状态。先停用代理扩展，用另一个浏览器形成对照。

退出后没网一定是 Clash 的问题吗？

不一定。浏览器代理、TUN 虚拟网卡、其他 VPN、加速器、DNS 缓存或组织策略都可能造成类似症状。
