Clash显示已连接但无法上网怎么办？

作者优质机场推荐编辑部 依据操作系统与 Mihomo 官方文档 更新2026-07-04

先判断：哪个环节没有工作？

“已连接”可能只表示客户端正在运行或已选择节点，不代表浏览器流量一定经过代理。先用同一浏览器打开两个不同网站，再切换一个节点；不要一开始同时修改系统代理、TUN 和 DNS。

如果订阅更新也失败，请先处理订阅更新问题；如果只有一个节点失败，优先按节点故障处理。

五分钟快速检查

  1. 切换到另一个地区的节点，再测试浏览器。
  2. 确认客户端当前使用的是系统代理还是 TUN，记下原状态。
  3. 关闭其他代理软件与浏览器代理扩展，避免多套规则争用流量。
  4. 换用手机热点测试一次，用来区分本地网络与客户端问题。
  5. 每次只改一项；无效就回退到原状态，再进入下一分支。

症状与排查入口

只有一个节点失败节点状态切换节点并查看服务商公告其他节点正常即可停止改本机设置

按可逆顺序继续排查

1. 节点与订阅

先切换节点，因为这是影响范围最小的对照。多个节点都失败且订阅更新时间异常时，先完成订阅更新排查；不要把旧配置当作当前服务状态。

2. 系统代理

系统代理决定遵循操作系统代理设置的应用把流量发往哪里。Windows 可在“设置 → 网络和 Internet → 代理”检查手动代理；macOS 可在“系统设置 → 网络 → 当前网络 → 详细信息 → 代理”检查。退出客户端后仍不能上网时，也要检查是否留下了无效的代理地址。

3. TUN 接管

TUN 会接管比系统代理更广的流量范围，具体行为取决于操作系统、权限和 Mihomo 配置。若问题恰好在开启 TUN 后出现，先回退到原状态验证，而不是同时更换 DNS 或复制别人的配置。

4. DNS 与本地网络

只有在节点和接管方式已形成清晰对照后再检查 DNS。换手机热点可以判断问题是否局限在当前 Wi-Fi；这个结果只说明网络路径不同，不能单独证明服务端或运营商故障。

安全恢复与停止条件

  • 改动前截图或记录系统代理、TUN 和 DNS 的原状态。
  • 每轮只改一项，测试无效立即回退，避免无法判断是哪项生效。
  • 不要从陌生来源复制未经核验的配置片段，也不要默认重装或删除全部配置。
  • 提交日志前遮盖订阅 URL、令牌、账号、节点地址和本地 IP。

常见问题

Clash显示已连接为什么还是打不开网页？

已连接不等于应用流量已经正确进入代理。先切换节点，再分别检查系统代理、TUN 和 DNS。

系统代理和TUN应该同时开启吗？

排障时不建议同时改变两项。先使用原来的接管方式测试，再一次只改一项，并保留回退路径。

换节点仍无法上网怎么办？

用手机热点形成网络对照，并确认系统代理没有遗留地址。若订阅也无法更新，应先排查订阅。
