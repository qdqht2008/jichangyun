# 导航栏重新设计方案

## 背景

重新设计网站导航结构，最上层为导航栏，包含四个主要入口：首页、机场推荐、使用教程、避坑指南。移除下载相关的链接。

## 设计决策

### 顶部导航栏
- **样式**：胶囊式导航
  - 激活项：背景色 `--accent-primary`，白色文字，圆角
  - 未激活项：纯文字，hover 时有轻微背景色过渡
- **高度**：约 60px
- **导航项**：首页、机场推荐、使用教程、避坑指南

### 左侧边栏
- 保持现有宽度（220px）和位置
- 根据当前分类动态显示子导航：
  - **首页**：无侧边栏
  - **机场推荐**：显示各机场列表（大哥云、飞秒云、光年、久链云、精灵学院等）
  - **使用教程**：显示各客户端教程（Clash Verge、FlClash、Clash for Windows 等）
  - **避坑指南**：显示避坑文章列表

### 移除内容
- 删除"下载中心"相关链接
- 删除首页的"客户端下载"卡片
- 保留其他功能（如评论区）

## 实现范围

1. 修改 `css/main.css` - 添加顶部导航栏样式
2. 修改 `index.html` - 添加顶部导航栏，移除下载相关链接
3. 修改各子页面（jichang/、tutorial/、guide/）的侧边栏逻辑

## 预期效果

顶部为醒目的胶囊式导航，用户可以快速切换主要分类；左侧边栏提供当前分类下的细分子导航，保持原有的网站结构完整性。
