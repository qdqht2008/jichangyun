# 机场推荐页面卡片样式优化设计方案

## 1. 概述与目标

参考 iroamix.com 的现代简约风格，优化 jichangyun 机场推荐页面的卡片设计。核心目标是：
- 提升卡片视觉层次感
- 增强 hover 交互反馈
- 统一首页（jichang/index.html）和机场详情页的卡片样式

## 2. 设计语言

### 2.1 卡片样式

| 属性 | 当前值 | 目标值 |
|------|--------|--------|
| 边框 | 1px solid var(--border-color) | 无边框，纯阴影 |
| 圆角 | 16px | 20px |
| 内边距 | 28px | 32px |
| 阴影 | 无 | 默认: 0 4px 20px rgba(0,0,0,0.06) |
| 阴影(hover) | 0 12px 40px rgba(224,122,95,0.12) | 0 16px 48px rgba(224,122,95,0.15) + translateY(-6px) |
| 左边框强调色 | 3px | 4px + 圆角端点 |

### 2.2 卡片结构

```
┌────────────────────────────────────────┐
│ [图标]  机场名称              [标签tag] │
│          简短描述文字                    │
│  ────────────────────────────────────  │
│  ✓ 特点1   ✓ 特点2   ✓ 特点3            │
│  ────────────────────────────────────  │
│  [查看详情 →]                           │
└────────────────────────────────────────┘
```

### 2.3 配色

- 保持现有 CSS 变量不变
- 强调色使用 var(--accent-primary) #e07a5f
- 成功色使用 var(--accent-secondary) #81b29a

## 3. 页面范围

### 3.1 需修改的页面

1. `/jichang/index.html` - 机场列表首页（主改）
2. `/jichang/ny/index.html` - 奈云详情页
3. `/jichang/dageyun/index.html` - 大哥云详情页
4. `/jichang/longmiaoyun/index.html` - 龙猫云详情页
5. 其他 jichang/ 下的机场详情页（统一样式）

### 3.2 CSS 改动集中管理

所有卡片相关样式统一放到 `/css/main.css` 中，使用统一 class：
- `.airport-card` - 基础卡片
- `.airport-card:hover` - 悬停状态
- `.airport-card-icon` - 机场图标区
- `.airport-tag` - 标签样式

## 4. 交互动效

- **默认状态**: 卡片静置，轻阴影
- **Hover 状态**: 上浮 6px + 阴影加深 + 左侧强调色显现
- **过渡时长**: 0.35s cubic-bezier(0.25, 0.46, 0.45, 0.94)
- **点击效果**: scale(0.98) 轻微按压反馈

## 5. 响应式适配

| 屏幕宽度 | 卡片列数 | gap |
|----------|----------|-----|
| >= 1200px | 3列 | 28px |
| 768-1199px | 2列 | 24px |
| < 768px | 1列 | 20px |

## 6. 实现优先级

1. **Phase 1**: 更新 `/css/main.css` 中的卡片基础样式
2. **Phase 2**: 更新 `/jichang/index.html` 应用新样式
3. **Phase 3**: 统一其他机场详情页的卡片 HTML 结构
4. **Phase 4**: 细节微调（间距、字体大小等）

## 7. 验证标准

- [ ] 卡片 hover 有明显上浮效果
- [ ] 左侧强调色条在 hover 时显现
- [ ] 移动端（375px）单列显示正常
- [ ] 平板（768px）双列显示正常
- [ ] 桌面（1200px+）三列显示正常
- [ ] 页面加载无布局跳动
