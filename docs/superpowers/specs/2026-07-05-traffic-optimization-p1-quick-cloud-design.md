# 网站流量优化 P1：Quick Cloud 评测重构设计

**日期：** 2026-07-05
**状态：** 已确认，待实施计划
**范围：** Quick Cloud 详情页、机场汇总页与 Sitemap

## 1. 目标

将 Quick Cloud 旧版图片套餐页改造成与前三批一致的编辑型评测页，以可检索的文字表格呈现当前套餐、适用场景和购买限制。同时停止在站内主动推荐光年梯与龙猫云，但不删除或更改两者详情页的索引设置。

保持纯 Cloudflare Pages 静态架构、现有暖色编辑型视觉和商业入口，不增加服务端、账号系统、测速或运行时数据源。

## 2. 已选方案

采用完整评测重构：更新谨慎 SEO、统一评测结构、文字套餐表、来源说明和结构化数据。拒绝只替换图片或在旧宣传文案上追加表格，因为旧文案中的强断言会与新的证据口径冲突。

光年梯与龙猫云采用“移除主动入口”方案：

- 删除机场汇总页的龙猫云推荐卡片；光年梯当前已无汇总页卡片。
- 从 Sitemap 删除光年梯与龙猫云 URL。
- 保留 `jichang/guangnian/index.html` 与 `jichang/longmiaoyun/index.html`，不加 `noindex`，不删除页面，不配置重定向。
- 不改历史设计与计划文档中的文字记录，也不把“光年 VPN 跑路案例”误判为光年梯推荐链接。

## 3. 证据来源与边界

套餐事实来自用户于 2026-07-05 提供并明确确认为当前 Quick Cloud 官方套餐页的文字。公开注册入口只用于确认商家页面可访问；未登录公开页不展示套餐，不作为套餐事实来源。

统一证据规则：

- 套餐名、价格、流量、周期、速率、设备规则、交付时间和客服说明可写成“官方套餐页显示”。
- IEPL、高速线路、住宅家宽、原生纯净节点、60+ 节点、流媒体/AI 解锁、冷门国家解锁和客服时效均是商家声明，不改写成本站验证。
- 不写本站测速、延迟、稳定性、解锁率、晚高峰表现或运营年限。
- 页面使用：“本文仅整理公开资料，实际体验因地区、运营商、设备和时段而异。”
- 不显示推广或佣金披露；商业 CTA 保持 `rel="sponsored nofollow noopener"`。

## 4. 页面结构

Quick Cloud 页面采用现有统一评测结构：

1. `review-meta`：官方套餐页、核验日期与体验边界。
2. 一句话结论：只总结起价、流量类型和定制方案，不作性能结论。
3. `适合人群` / `不适合人群`：从套餐结构与明确限制推导。
4. `可核验特点`：当前套餐页直接陈述的事实。
5. `限制与购买前确认`：退款信息缺口、解锁/线路声明边界、活动与库存变化。
6. 月付套餐与不限时流量包的响应式文字表。
7. 节点定制的独立说明，不与普通订阅套餐混表。
8. 商业 CTA、谨慎体验提示、信息来源、FAQ 和相关指南内链。

样式复用 `css/main.css` 的现有评测组件。没有共同样式缺口时不改 CSS，不保留旧套餐截图作为当前价格证据。

## 6. 节点定制

节点定制单独呈现为高门槛方案：

- ¥189/月，流量按月重置。
- 托管式：2500GB，商家注明针对托管式为 8 倍率、不限制同时在线设备，用户付费后使用。
- 非托管式：默认 1000GB、无倍率，可登录服务器 root 并自行部署；商家不提供节点技术服务，但可协助重启、重装或服务器故障处理。
- 商家注明最高峰值 1000Mbps，节点不与他人共享，并称为独立原生纯净节点。
- 可定制日本、新加坡、台湾、韩国、法国、德国、西班牙；某些地区可额外付费增加原生 IP，但交付后不能新增。
- 下单后需工单说明托管式或非托管式，商家称 3 个工作日内交付并提供 7×24 小时技术支持。
- 下单前必须联系在线客服或工单确认库存；特殊需求可能额外收费。

页面不替用户判断托管式与非托管式的实际性能，也不把“独立”“原生”“纯净”改写成本站技术验证。

## 7. 风险与购买前确认

首屏和购买区至少明确以下事项：

- 官方资料没有提供普通套餐的设备数量、限速和退款规则，购买前需向客服确认。
- 线路、节点类型和解锁能力来自商家描述，实际结果受网络与平台策略影响。
- 一次性流量包不按月重置，但“不限时”不等于服务持续性的保证。
- 节点定制需先确认库存、托管方式、额外 IP 与潜在额外费用；非托管式要求用户自行部署。
- 活动未给出规则和截止时间，结算价格与资格以下单页为准。
