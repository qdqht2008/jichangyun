适合谁？

适合需要在 Android 导入 Mihomo/Clash 配置的用户。该应用通过 Android 系统 VPN 接口接管流量。

版本与 APK 架构

截至 2026-07-04 核验：v2.11.30。下载前在官方 Release 再确认版本与资产。

APK 类型适用情况注意
arm64-v8a许多较新的 64 位 ARM 设备先在设备信息确认 ABI
其他架构按官方 Release 资产说明不要仅凭手机品牌猜测
Android 系统 VPN启动代理时授权系统提示本身不是故障
后台限制锁屏或切后台后中断只调整该应用的电池策略

官方下载

打开 CMFA 官方最新 Release

核对 Android 版本、ABI 与文件名；本站不提供 APK 镜像。

最短配置路径

确认架构并安装

从官方 Release 选择匹配设备 ABI 的 APK，按 Android 正常安装流程操作。

导入订阅

在配置页面添加服务商后台提供的订阅 URL 并更新。

选择节点

选择一个节点，先保持规则模式进行验证。

授予 VPN 权限

点击启动后接受 Android 的系统 VPN 授权；若后台断线，再检查该应用的电池与后台限制。

安全与隐私

不要安装来源不明的 APK，也不要公开订阅 URL、令牌、账号、节点地址或本地 IP。排障只调整该应用所需设置。

按症状排查

  • 订阅更新失败
  • 已连接但无法上网
  • 无法连接或频繁断线

VPN 权限提示正常吗？
