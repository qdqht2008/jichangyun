Clash Verge Rev 下载与配置教程

作者优质机场推荐编辑部依据项目官方 Release更新2026-07-04

适合谁？

适合需要在 Windows、macOS 或 Linux 导入 Mihomo/Clash 订阅的桌面用户。不同系统的安装包与权限不同，不能混用。

版本与平台怎么选

截至 2026-07-04 核验：v2.5.1。官方说明当前版本不再支持 Windows 7；下载前仍应在 Release 页面复核。

平台常见选择判断方式
Windows x64x64 setup多数 Intel/AMD 电脑
Windows ARM64ARM64 setup仅 ARM Windows 设备
macOS Apple 芯片aarch64 DMGM 系列芯片
macOS Intel 芯片x64 DMGIntel 处理器
LinuxDEB / RPM按发行版与架构选择

官方下载

打开官方最新 Release

核对版本、系统、架构和文件名后再下载；本站不提供第三方镜像。

最短配置路径

安装并启动

使用与系统和架构匹配的官方安装包。

导入订阅

从服务商后台复制订阅 URL，在配置或 Profiles 页面添加并更新。

选择节点

在代理组中选择节点，先使用规则模式验证基本连接。

启用接管

系统代理适合遵循系统代理的应用；TUN 接管范围更广。一次只改变一种方式，并保留回退路径。

安全与隐私

只从官方 Release 下载。分享截图或日志前遮盖订阅 URL、令牌、账号、节点地址和本地 IP；不要为了安装而关闭系统安全保护。

按症状排查

  • 订阅更新失败、401/403 或解析错误
  • 显示已连接但无法上网
  • 无法连接或频繁断线

常见问题

系统代理和 TUN 要同时开启吗？

不需要。排障时一次只验证一种接管方式。

Windows 7 能用当前版本吗？

v2.5.1 官方 Release 标明不再支持 Windows 7。
