# 网站流量优化：核心入口证据同步设计

**日期：** 2026-07-05
**状态：** 已确认，待实施计划
**范围：** 首页、机场汇总页、Sitemap 与站点审计

## 1. 目标

让首页和机场汇总页与已经核验的机场详情页使用同一证据口径。核心入口只展示可追溯的价格、流量、周期和明确限制，不用“稳定快速”“不跑路”“全解锁”“实测”等未经本站观测支持的承诺吸引点击。

本批只同步既有内容，不新增机场事实，不修改详情页，不引入服务端或运行时数据源。

## 2. 首页信息架构

首页保持现有暖色编辑型布局、三类内容入口和资源列表，只收紧文字与元数据。

### 2.1 SEO 与首屏

- 标题聚焦“Clash 机场推荐、客户端教程、故障排查”，不宣称稳定节点或免费订阅。
- description、Open Graph 和 Twitter 描述只说明本站整理套餐、客户端配置与排查指南。
- 首屏说明改为“整理公开套餐资料、配置教程和避坑指南”，删除“不踩坑、不跑路”和畅通保证。
- 机场入口卡改为“套餐价格、流量限制、购买风险”。
- 百科入口卡改为“购买避坑、故障排查、线路原理”，删除“稳定性实测”。
- 不改品牌名“优质机场推荐”；该名称是站点身份，不作为单个商家的质量结论。

### 2.2 四条机场入口

首页继续保留四条已有详情页链接，但摘要与核验页一致：

| 页面 | 首页摘要 |
| --- | --- |
| 扬帆云 | ¥19.99/月起，100GB–1.2TB/周期 |
| Quick Cloud | ¥12.9/月起，含不限时流量包 |
| 飞鸟云 | ¥12/年起，含月付与不限时流量包 |
| 大哥云 | ¥19.90/月起，新疆地区不可用 |

首页不重复线路、协议、节点数量或解锁声明，避免脱离详情页归因上下文。

### 2.3 更新记录与日期

- 将首页更新记录中的“首页资源导航升级”改为“首页机场摘要与证据口径同步”。
- 该记录日期改为 2026-07-05。
- Sitemap 首页 `lastmod` 同步为 2026-07-05。
- 首页无 Article JSON-LD，不为本次新增虚假的发布日期字段。

## 3. 机场汇总页

### 3.1 首屏与方法说明

- 副标题改为“按公开套餐资料整理价格、流量与购买限制”，不保证节点稳定或速度。
- 购买提示聚焦退款、设备、地区和长期套餐风险，删除“不跑路”和“避开 90% 的坑”。
- 保留避坑指南链接，但锚文本不承诺效果比例。
- 方法说明改为：编辑部逐批核对官方套餐页与可追溯公开资料；卡片显示各自核验日期；商家线路和解锁描述不等于本站测试。
- 保留统一体验边界：“本文仅整理公开资料，实际体验因地区、运营商、设备和时段而异。”

### 3.2 优信云退出

删除优信云整张卡片，原因是当前没有详情入口、核验日期或本批可引用的官方套餐证据。此次只删除汇总页展示：

- 不创建优信云详情页。
- 不推断商家状态或写“跑路/停运”。
- 不改历史文档中的文字记录。
- Sitemap 当前没有优信云 URL，无需新增或删除条目。

其余机场卡片顺序、摘要、核验日期和链接保持不变。

## 4. 证据与措辞边界

- 首页四条机场摘要只复制已通过审计的详情页或汇总卡事实。
- 不把商家宣称的协议、线路、节点、解锁、客服或稳定性搬到首页。
- 不写本站测速、稳定性排名、推荐分数、运营年限或跑路概率。
- 不因本次文案同步更新任何机场详情页 `dateModified`。
- 不加入可视推广/佣金披露；本批不修改商业 CTA。

## 5. TDD 与验证

先写失败测试并观察 RED，再修改两个入口：

- 首页四条机场链接与精确摘要存在，旧协议、线路、节点和“老牌”摘要消失。
- 首页 title、description、首屏和入口卡不含稳定保证、免费节点、不跑路或实测暗示。
- 首页更新记录与 Sitemap 日期均为 2026-07-05。
- 机场汇总页副标题、提示和方法说明符合谨慎证据口径。
- 汇总页不存在优信云卡片及相关无证据宣传。
- 其他机场卡片的名称、链接、摘要与核验日期不被本批改动。
- 全量 Node 审计零失败、零跳过，`node --check js/nav.js` 与 `git diff --check` 通过。

浏览器在桌面和 390px 检查首页与机场汇总页：文字不溢出、资源列表和机场网格保持响应式、优信云不可见、控制台无本批引入的本地资源错误。

## 6. 完成条件与非目标

完成条件：两个核心入口只使用已核验摘要和谨慎方法说明，优信云退出汇总展示，自动与浏览器验证通过，并创建本地提交。

本批不包含：

- 新机场评测或现有详情页更新。
- 月度稳定性报告、测速或商家状态判断。
- GitHub、视频、社区发布或自然外链操作。
- 推送、部署或 GA4 管理端修改。
