适合谁？

适合希望在 Windows、macOS、Linux 或 Android 使用同一项目的用户。各平台安装包、权限和界面入口不完全相同。

版本与平台选择

截至 2026-07-04 核验：v0.8.93。下载前仍应在官方 Release 确认当前版本。

平台选择重点接管方式
Windowsx64 或 ARM64系统代理 / TUN
macOSApple 芯片或 Intel系统代理 / TUN
Linux发行版与架构依桌面环境设置
AndroidAPK 与设备架构系统 VPN

官方下载

打开 FlClash 官方最新 Release

最短配置路径

安装

选择与系统和处理器匹配的官方资产。

导入订阅

在配置页面添加服务商后台提供的订阅 URL 并更新。

选择节点

先选择一个节点并使用规则模式验证。

启用接管

桌面端选择系统代理或 TUN；Android 接受系统 VPN 权限后启动。

安全与隐私

不要公开订阅 URL、令牌、账号、节点地址或本地 IP。不要为排障关闭系统安全保护。

按症状排查

  • 订阅更新失败
  • 已连接但无法上网
  • 无法连接或频繁断线

各平台操作完全一样吗？

不完全相同，应以当前平台界面和官方 Release 为准。
